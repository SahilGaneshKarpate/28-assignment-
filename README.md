# 📝  Natural Language Processing (NLP) Text Preprocessing

## Project Overview

This project demonstrates the fundamental text preprocessing techniques used in Natural Language Processing (NLP) with the Emotion Dataset. The assignment focuses on cleaning and preparing raw text data for future Machine Learning and Deep Learning applications.

The project includes dataset loading, label encoding, text cleaning, stopword removal, text length analysis, and exporting the processed dataset.

---

## Objectives

* Load the Emotion Dataset
* Explore emotion categories
* Encode emotion labels
* Convert text to lowercase
* Remove punctuation
* Remove numbers
* Remove emojis and special characters
* Remove stopwords
* Build a complete text preprocessing pipeline
* Analyze text length distribution
* Save the cleaned dataset

---
